Three steps

How Workspace Reflow works

  1. 01

    Select

    Press Alt + Shift + R, move over the live region you need, and click.

  2. 02

    Read

    Choose type size, line width, and light or dark contrast. Use J/K or arrow keys sentence by sentence.

  3. 03

    Return

    Save one rule for the site. The pane reopens on your next visit, while Escape returns focus to the page.

What stays visible

Keep nearby controls and task context visible

Workspace Reflow isolates only the region you choose. On desktop, navigation, status, and nearby task context remain visible beside it.

  • Live region updates flow into the pane
  • Headings, lists, links, labels, and image text alternatives remain semantic

Product limits and privacy

Questions before you install

Is this a screen-reader replacement?

No. It is an intermediate visual reading tool for people who need stronger reflow than browser zoom provides. It preserves useful semantics, but it does not replace assistive technology.

What leaves my device?

No page content, selected text, rule, or preference. Only an optional supporter license token is sent to Sociobot when you ask to verify it.

Will it work on every page?

Use it on ordinary website pages you are allowed to access. Browser internal pages do not allow extensions. Sites that rebuild their markup may require you to select and save the region again.
